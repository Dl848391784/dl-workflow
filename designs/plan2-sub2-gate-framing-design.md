## 2. 反转后的判据设计（默认-PASS framing）

结构：形式要件（保留 _TB_STEP2_FORM_REQUIREMENTS）+ 默认 pass 声明 + **六方框**
（每条 block面+legal面 近端双侧钉死，词形取 §1.1 误判判词逐字）+ 【判材边界】段
+ 【合法正例】段 + 条款引用要求。

- **方框一·横向按层切无辩护**（vio1，正判定）：block 面=单元按架构层（数据层/
  逻辑层/表现层等）横向切分却无显式辩护判 block；legal 面=纵向切片/横向附辩护/
  自述「非横向按层切」即合规，不得索取「为何不能纵向切」的代码级证明。
- **方框二·排序违反依赖**（vio2，正判定）：block 面=拓扑序把被依赖者排在依赖者之后
  判 block；legal 面=被依赖者先行即合规。判面=trace 内声明依赖 vs 拓扑序自洽，
  **不核 db 实际依赖真实性**（治聚类 5）。
- **方框三·超 H9 预算无继续拆**（vio3，正判定）：block 面=自报预算超 ≤3 文件或
  ≤200 行且无继续拆表述判 block；legal 面=≤限即合规/超限附拆方案即合规。**预算是
  估计值，judge 不复核含测试行数/准确性/是否该拆**（治聚类 3）。
- **方框四·要素 ID 覆盖有漏**（vio4，跨步一致性）：block 面=S1 要素清单某要素 ID 无
  单元承接判 block（S1 在载荷内可见，逐项对照）；legal 面=每要素 ≥1 单元承接即合规。
- **方框五·单阶段无论证**（vio5，**负判定缺席型**）：block 面=声明「单阶段/不可拆」
  却无「H9 内一次可完」量化论证（文件数+行数 ≤ 上限）判 block；legal 面=多阶段附
  断点方法（走另一分支）/单阶段附 H9 量化论证即合规。**㊳ 预测崩牙高危**：负判定
  default-PASS 下 judge 不主动查->v1 大概率 <5/6，§3 评估 mech 下沉。
- **方框六·替用户拍板断点**（vio6，正判定）：block 面=断点/粒度以定案口吻（「已确定/
  已定/设在」）无「提案-待裁决」语义判 block；legal 面=「提案/待裁决/候选」任一在场
  即合规；断点验证方法具体即合规，不得以「太具体不算提案」为由 block（治聚类 6）。

【判材边界】（治聚类 1/2/4/5）：S1 元素基线载荷内可见->要素覆盖可判；codegraph db
不可见->依赖真实性只判留痕在场（声明依赖+查询命令+返回概述），不核 db 实际调用关系
（不得以「U2 实际不依赖 U1/二者无实质依赖」block）；H9 预算=估计->不复核准确性/含
测试行数；完整测试周期=failing test 先行即合规（不得要求通过测试+验证闭环展开）；
字段⑧=设计包内部字段（judge 读不到设计包），不得以「未声明字段⑧精化不重做」block；
codegraph 留痕=查询命令+返回概述即合规，不得索取输出原文/节点 ID。

【合法正例】（各聚类合法形态落位）：codegraph 命令+概述（不贴原文）；声明依赖（不核
db）；H9 预算估计值（不索测试行数）；failing test 先行（不要通过测试闭环）；单阶段+
H9 量化论证；提案语义+具体断点方法。

## 3. mech 下沉（三 mech，⑯-safe 纯 token 扫描）

## 4. 泛化沉淀候选（本节点新教训，先记不落 rubric）

1. **mech 注册的 harness 注是 clean 误伤的隐藏杠杆**（㉙ harness 注变体）：三 mech 注册
   后 harness 注「已通过 mechanical 校验：X、Y、Z」使 judge 在对应判据上放宽=clean 误伤
   清零。先前节点（plan:2#1）mech 注册未观察到此 clean 杠杆（其 clean 误伤在原文引用，
   mech 不直接覆盖该误伤）。**操作化**：mech 下沉不只托 vio 牙，还压 clean 误伤--mech
   列表进 harness 注后须复测 clean（可能升 6/6）。待复核：是否普适（mech 覆盖的判据恰好
   是 clean 误伤源时才触发）。
2. **跨参照判据的两种崩法须分治**（㊻ 扩展）：vio2（同 trace 内声明依赖 vs 拓扑序）与
   vio4（跨步 S1 vs S2）都属跨参照，但 vio2 在 v4+mech 下 judge 仍 5/6（同 trace 对照较
   易）、vio4 仅 2/6（跨步对照较难）--跨步比同 trace 更依赖 mech。判据归位时区分「同 trace
   跨字段」vs「跨步」前者措辞可救、后者 mech 优先。
3. **逐答案扫描 vs 全量扫描**（⑭ 词形切分变体）：single_phase_argument 的违规信号（单阶段
   声明）与合法信号（H9 量化）可能分处不同答案（vio5 的单阶段在 a[2]、单元预算在 a[0]），
   全量扫描把 a[0] 的单元预算误当②论证放过。负判定 mech 须按「声明与合法留痕同段」假设
   逐答案扫，非全量。
4. **判材边界须显式覆盖②论证充分性**：judge 会 second-guess「3 文件 75 行 合计是否算②
   论证/H9 是单单元不是合计」（vio2[6]/clean 误伤）--判材边界须钉「量化在场即合规，不
   复核论证充分性/合计是否算论证/单阶段是否真不可拆」。
