## 2. 设计决策（v1）

1. **framing 反转**：默认 pass + 明列 block 条件（「默认 pass」字面=run_judge 双态单源，v2.76）。
2. **方框一·编造**（聚类 4/5 双侧）：block 面=声称既有符号「存在/已核实/可复用」却无出处
   （无 file:line 且无工具查询留痕）；合法面=file:line 或查询摘要（查询方式+返回概述）即合规，
   不得索取原始输出全文/节点 ID/命令完整回显；新增文件免存在性核实；判材边界=只判留痕在场，
   不核 db 真值。
3. **方框二·影响面拍脑袋**（聚类 3 反锚）：block 面=③无 impact 返回留痕凭估计给数字或
   「影响面小/可控」笼统结论；合法面=callers 数+名单即合规，「callers N 个」与「不改签名
   零改动」并存合法不矛盾；新文件「impact 不适用+形态说明」合规。
4. **方框三·无差别可行**：block 面=全候选同态且核验内容跨候选笼统趋同（无量化数字、无
   file:line、无规则点名）；合法面=内容随候选分化即合规；三态是类目不是配额（聚类 2 的
   「全覆盖」发明反锚），同落一态各有具体留痕合规。
5. **方框四·重复实现漏检**（判面收窄）：block 面=声称「无同功能实现/需新建」却无 codegraph
   （或 Grep）同功能查询留痕；合法面=查询方式+返回摘要（含空结果留痕）即合规；判材边界=
   只判查询留痕在场，不核代码库真实重复实现。
6. **方框五·缺项**（㊽ 形式要件方框化）：block 面=①-⑤任一项无任何内容或未给三态标注；
   合法面=「不适用+原因」声明不算缺项。
7. **【关键】段**（聚类 1/2/3/6/7/8/9 的合法面钉死）：三态逐候选整体标注非逐项；「可行」
   附出处即合规不索置信度；置信度档位+一句理由即合规；证伪剔除附理由即合规（可引本步③
   量化结果）；硬规则点名命中+「H11-H13 不触及」式声明即合规、不得核对条文细节；前序
   trace 只作组成事实、本步无跨步一致性判据。
8. **pin 零改动**：test_step3_feasibility_fence 的 needle（sub_step==3/编造/漏检/拍脑袋）
   在方框标题全部保留。
