### 1.1 误伤模式聚类（clean 6 轮判词逐字）

1. **worker 任务包字段样例要件**：「未给出每个 worker 包实际包含的字段
   （任务 ID、依赖声明、目标文件路径、判据命令、验收包 ID 引用、goal
   anchoring 重述句等）样例，无法验证零上下文可执行」——发明要件。
2. **密度论证数值要件**：clean 选可逆性×爆炸半径路径，judge 仍索复利论证
   的「逐步成功率 p_i 估计与整体下界∏p_i」——两路径二选一被读成都要。
3. **类型论证深度要件**：「CP1 自动继续未论证为何不需暂停」——clean 已附
   两因子+建议，judge 索论证深度。
4. **「输出含…断言通过」被读成判断词**：CP2 判据「pytest …退出码 0 且输出
   含八维度断言通过」被判「含…通过」类确认词违反零判断词——断言锚定形
   被误读。
5. **judge 自行重推 DAG 判分组错误**：拿子1 trace 重推拓扑后断言
   「L2={T2}、L3={T3}」分组拍脑袋——拓扑正确性复核是发明要件（且重推
   本身错了）。
6. （vio 判词附带暴露）**三选一显式锚定要件**：「返工本组（W1 重做 T1）」
   被多轮判「未显式锚定三选一类别」——语义可归类被要求字面类别名。
7. （vio 判词附带暴露）**红队阈值定义要件**：条件未触发声明附计数被索
   「阈值定义与未触发论证」。

## 2. 反转后的判据设计（默认-PASS framing）

形式要件段保留 `_EPC_STEP2_FORM_REQUIREMENTS` 常量单源（purpose/gate 双
引用，㉘ 插值 gate 落地后展开逐字比对）。六方框 = 原六条从严判据逐条
双侧化（block 条件 + 合法形态钉死，词形取 §1.1 聚类逐字）：

- 方框一（虚设判据）：双侧钉「输出含 X 断言/断言通过=断言锚定形非判断词」
  （聚类 4）+「判断词禁令只约束通过判据行，goal anchoring/描述句的
  待验/确认类词不判」（聚类 8）。
- 方框二（即兴路由）：双侧钉「语义落三选一即合规，不要求显式标注类别名」
  （聚类 6）。
- 方框三（拍脑袋分组）：双侧钉「清单粒度/路径写法差异不判，交集实算归
  子3」+纯串行 DAG 豁免形。
- 方框五（逃避论证）：双侧钉「两路径任一在场即合规，选可逆性×爆炸半径
  路径不得再索复利论证数值；论证篇幅深度不判」（聚类 2/3）。
- 方框六（越权拍板）：双侧钉「方案内容具体完整不判，只判是否替用户定案」。
- 【命题性质】段（㉚①）：dry-run/交集实算/任务 ID 存在性归子3；拓扑分层
  正确性不判、不得自行重推 DAG（聚类 5）；worker 任务包映射给自包含要素
  声明即合规，不得索逐字段样例（聚类 1）。
- 【判材边界】段：四源文件读不到，出处真实性不判；红队未触发声明附计数
  即合规，不得索阈值定义（聚类 7）。

## 4. 泛化沉淀候选（本节点新教训，先记不落 rubric）

1. **拼接脚本 f-string 行的标点陷阱（㉕ 第四变体）**：形式要件段保留常量
   单源时，落地行 `f"形式要件：{CONST}\n"` 容易漏掉常量后的「。」——
   第一次 splice 漏「。」（len 差 1），第二次补成独立行 `"。\n"` 又多一
   个换行（「拍板）\n。\n默认」），两次都被一致性断言当场逮住。教训：
   落地区块与原区块的逐字差异只能有**显式声明的那一处**（本例=记录；
   vs 记录。），断言不过就 diff 到第一个字符，不许「大概对齐」。
2. **vio 载荷 replace anchor 防哑弹断言**：vio 载荷用 `.replace()` 从 clean
   派生时，anchor 未命中=静默等于 clean=哑弹载荷（v1 重放会假阳性通过
   vio 列）。模块加载即断言 `vio != clean` 零成本兜底（本 replay 首创，
   后续 replay 可抄）。
3. **一轮达标第四例再证 ㉛**：六方框各自钉死无共享旋钮（⑲ 分治的反面
   实例——方框间词形零重叠时一轮可达）；基线牙齿全满仍是最强预测因子。
